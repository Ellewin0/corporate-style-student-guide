JSON structure expected by this formatter

The formatter accepts a flexible structure. The recommended fields are:

{
  "title": "Guide title",
  "subtitle": "Student Guide",
  "audience": "Students",
  "purpose": "What this guide helps students do",
  "version": "v1.0",
  "status": "Draft / Published",
  "sections": [
    {
      "number": "1.0",
      "title": "Introduction",
      "subsections": [
        {
          "title": "What is it?",
          "paragraphs": ["Plain English explanation."],
          "steps": ["Step one", "Step two"],
          "tip": "Helpful tip",
          "imagePlaceholder": "Screenshot title",
          "imageDescription": "Specific accessible description."
        }
      ]
    }
  ],
  "helpfulTips": [{ "tip": "", "whyItHelps": "" }],
  "troubleshooting": [{ "issue": "", "whatToTry": "" }],
  "faqs": [{ "question": "", "answer": "" }],
  "whereToGetHelp": ["[Insert confirmed support contact]"]
}
